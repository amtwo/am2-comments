# am2-comments

This public repository stores the GitHub Discussions used by [am2.co](https://am2.co/) through [Giscus](https://giscus.app/). The website source and content live in a separate repository; this repository is for discussion threads and comments only.

## How comments work

- Giscus maps each page to a discussion using its URL path.
- New page discussions are created in the **Announcements** category. This category is intended for posts created by repository maintainers and Giscus, while visitors can reply to the threads.
- Visitors sign in with GitHub to comment. Discussions and comments are public and can be moderated here.
- Keep existing discussion threads when updating the website. Stable page paths keep comments associated with the right post.

The Giscus app must be installed for this repository, and GitHub Discussions must remain enabled.
